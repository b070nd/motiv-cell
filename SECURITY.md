# Security Policy

## Supported Versions

Only the latest commit on `main` is supported.

## Reporting a Vulnerability

Please do not open a public issue for security problems.

Report privately through GitHub: https://github.com/b070nd/motiv-cell/security/advisories/new

Include the affected package, a minimal input that reproduces the problem, and the Go version used. You can expect an acknowledgement within 7 days.
